# Feature metadata

Generated by `src/features/preprocess.py`
Input: `data/raw/github_repositories.csv`
Output: `data/processed/features.csv`

---

## Important Note on Target Variable
Models are trained on `log_stars`, NOT raw star counts.
To convert predictions back to real star counts:
```python
predicted_stars = np.expm1(predicted_log_stars)
```

---

## Target Variable

| Column | Type | Description |
|---|---|---|
| `log_stars` | float | log1p(stars): normalized star count. This is what models should predict. |

## Dropped columns and reasons

| Column | Reason for Dropping |
|---|---|
| `stars` | Replaced by `log_stars` as target variable |
| `watchers` | Identical to `stars` across all 1000 repos, so data leakage |
| `name` | Identifier only, no predictive value |
| `full_name` | Identifier only (owner/repo format), no predictive value |
| `created_at` | Raw date string, derived into `repo_age_days` instead |
| `updated_at` | All top 1000 repos updated within 2 days, zero variation, no predictive value |
| `description` | Raw text, converted to `has_description` binary |
| `homepage` | Raw text, converted to `has_homepage` binary |
| `license` | Raw text, converted to `has_license` binary |
| `topics` | Raw text, converted to `topics_count` numeric |
| `language` | Raw string, one-hot encoded into `lang_*` columns |
| `is_fork` | All top 1000 repos are original projects, zero variation, no predictive value |
